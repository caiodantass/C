# 📘 Projetos em Linguagem C

Este repositório contém **provas e atividades da disciplina de Linguagem C**, com exercícios e avaliações feitos ao longo da matéria.

Os arquivos no repositório (ex.: `.zip` e `.odt`) correspondem às avaliações realizadas, mostrando o uso da **linguagem C** na resolução de problemas e na implementação de lógica de programação.

O objetivo deste repositório é **mostrar minhas soluções e entendimento da linguagem C** por meio de atividades acadêmicas da disciplina, servindo como portfólio de estudos.
